# 优先级 · 互动视觉小说工程包

静态网页游戏：HTML + CSS + 原生 JavaScript，无后端、无真实账号、无真实文件加密或第三方服务。

## 版本内容

- 共 **10 章**，包含分支选择、聊天模拟、轻解谜、章节回看、本地存档、两种结局。
- 中文为**默认语言**；首次打开显示中文，右上角按钮显示“中”。
- 点击右上角语言按钮，可在弹窗中切换“中文 / English”。语言偏好保存在当前浏览器，不改变剧情、谜题答案或存档数据。
- 38 件已收集回忆可点击查看，每件有一句话介绍。
- 已适配桌面、手机竖屏/横屏、iPad 竖屏/横屏、窄分屏、刘海与底部安全区，并处理输入密码时的软键盘视口。
- 包含当前全部 20 张经尺寸优化的 WebP 场景/聊天插画。

## 本地运行

直接双击 `index.html` 通常即可运行。若浏览器对本地脚本或图片有限制，在本目录启动一个静态服务：

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

然后打开：

```text
http://127.0.0.1:8080/
```

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面结构 |
| `style.css` | 原有视觉风格 |
| `responsive.css` | 手机、iPad、分屏、横竖屏和安全区适配 |
| `story.js` | 全部章节、对白、任务、结局和回忆介绍的规范数据 |
| `game.js` | 渲染、交互、存档、章节回看和弹窗逻辑 |
| `i18n.js` | 英文显示词典；不参与中文存档数据 |
| `locale.js` | 中英语言选择与显示层翻译 |
| `viewport.js` | 动态视口、屏幕旋转和软键盘适配 |
| `assets/` | 当前游戏使用的全部插画 |
| `tests/legacy/` | 历史开发期 Playwright 脚本 |

## 存档与语言

- 游戏进度仅保存在当前浏览器的 `localStorage`。
- 存档 key 为 `vn:priority-orange-20260916:v3`。剧情数据仍为中文规范值，英文只是显示翻译。
- 语言偏好 key 为 `vn:priority-orange-20260916:language`，默认中文；不存在该偏好时也显示中文。
- 删除浏览器站点数据会同时清除游戏进度和语言偏好。

## 继续编辑

修改剧情请编辑 `story.js`，同步更新 `i18n.js` 中相应的英文显示词条。避免随意改动节点 ID、谜题答案、存档 key 和迁移映射，以免破坏存档兼容性。插画通过 `assets/` 引用，包内未包含系统字体文件，字体由设备自带字体回退。

## GitHub Pages 发布说明

本仓库作为独立静态网站发布，不携带原平台的页面身份配置。所有插画已压缩为最长边不超过 1600px 的 WebP，并通过 `object-fit: contain` 保证主要游戏场景完整显示；空余区域使用柔化背景填充。

浏览器存档与语言偏好按域名隔离，因此 GitHub Pages 与其他发布地址的进度不会互通。

## 测试

`tests/legacy/` 是历史开发期脚本，部分章节/节点断言早于当前十章和后续新增剧情，**不代表最终完整回归通过结果**，仅作继续开发时的参考。需要时先更新其中章节数、节点 id 和选择路径。

历史脚本需要 Node.js、Playwright 与 Chromium：

```sh
npm init -y
npm i playwright
npx playwright install chromium
node tests/legacy/new-asset-check.cjs
```

当前交付前已使用网页校验工具检查桌面、平板、手机三档视口，未在所有实体机型上逐台真机测试。
